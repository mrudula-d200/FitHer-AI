# 🌸 FitHer AI

FitHer AI is a personalized AI-powered fitness and wellness assistant designed to help women with workouts, nutrition, and healthy fitness habits.

## ✨ Features

- 👤 Personalized fitness profile
- 📏 Height input in feet and inches
- ⚖️ BMI calculation
- 🔥 Daily calorie estimation
- 💪 Protein estimation
- 💧 Water intake estimation
- 🏋️ Personalized workout plans
- 🍎 Personalized nutrition plans
- 🥗 Vegetarian, Non-Vegetarian and Vegan options
- 🤖 AI fitness chatbot
- 💬 Quick fitness questions
- 🎀 Beautiful light-pink user interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Gemma 3:1B
- HTML
- CSS
